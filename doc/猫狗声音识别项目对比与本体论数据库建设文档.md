## 1. 概述

### 1.1 技术背景

猫狗声音识别（Canine/Feline Vocalization Recognition）是生物声学（Bioacoustics）与人工智能交叉的前沿领域。其核心目标是通过分析猫和狗发出的声音（吠叫、呜咽、嚎叫、喵叫、呼噜声等），实现对动物情绪状态、行为意图、健康状况的自动识别。

与语音识别（ASR）不同，动物声音识别面临独特挑战：
- **缺乏大规模标注数据集**：远不及人类语音数据集（LibriSpeech、Common Voice）的规模
- **声音变异度高**：同种动物在不同品种、年龄、情绪下的声音差异显著
- **背景噪声复杂**：真实环境中常混杂多种环境噪声
- **标注主观性**：动物情感/意图标注依赖于人类主观解释，缺乏客观金标准

### 1.2 应用场景

| 场景 | 说明 |
|------|------|
| 宠物健康监测 | 通过声音识别宠物的痛苦、焦虑、疾病信号 |
| 智能宠物设备 | 智能项圈、宠物摄像头中的声音事件检测 |
| 动物福利评估 | 收容所、养殖场中动物情绪状态批量分析 |
| 宠物翻译/沟通 | 面向消费者的"猫语/狗语翻译"应用 |
| 城市安防 | 检测流浪狗聚集、犬吠扰民等事件 |
| 兽医辅助诊断 | 结合声音特征辅助判断呼吸道疾病、疼痛等 |

### 1.3 GitHub 生态总览

通过对 GitHub 的多维度搜索（涵盖 `dog bark detection`、`cat meow classification`、`animal sound recognition`、`pet vocalization`、`audio event detection` 等 20+ 组关键词），共发现 **约 35 个直接或间接相关的开源项目**。

**生态特征：**

1. **缺乏大型旗舰项目**：与计算机视觉领域的 YOLO、ResNet 不同，猫狗声音识别领域没有 Stars 过百的专用项目。最高 Stars 的项目是通用音频分析库 `pyAudioAnalysis`（6251 Stars），但它并非猫狗声音专用。
2. **狗类项目多于猫类**：狗吠声检测在环境声音分类（UrbanSound8K）中是标准类别之一，相关项目较多；猫叫声识别项目更为稀缺。
3. **学术驱动为主**：绝大多数项目来自大学课程作业、学术论文的代码实现，工业级产品较少。
4. **数据集是核心瓶颈**：DogSpeak（2025年ACM Multimedia发表）和 CatMeows（米兰大学）是目前最主要的公开数据集。
5. **技术栈以 CNN + MFCC 为主流**：超过 80% 的专用项目采用此技术路线。
6. **Wav2Vec/Transformer 路线兴起**：m3hrdadfi/soxan（276 Stars）、HTS-Audio-Transformer（500 Stars）等通用模型展示了将大规模预训练模型迁移到动物声音识别的潜力。

## 3. 技术方案对比

### 3.1 按技术路线分类

#### 路线一：传统机器学习 + 手工特征

**代表项目：** `pyAudioAnalysis`（6251 Stars）、`ravising-h/Urbansound8k`（76 Stars）、`BenjaminDoran/Urban-Sound-Classification`（55 Stars）

**核心方法：**
- 特征提取：MFCC、Chroma、频谱质心、过零率、频谱滚降等
- 分类器：SVM、Random Forest、XGBoost、k-NN
- 流程：音频 → 短时帧分割 → 特征提取 → 统计池化(均值/方差) → 分类器

**优势：**
- 计算效率高，可在嵌入式设备运行
- 小样本场景表现不差
- 可解释性强，特征有物理意义

**劣势：**
- 需要大量特征工程经验
- 对复杂非线性模式建模能力有限
- 泛化能力弱于深度学习方法

#### 路线二：CNN + 频谱图

**代表项目：** `CrispenGari/animal-sound-classification`（8 Stars，90.7%准确率）、`hemo528/CatMeows_recogintion`（6 Stars）、`Yfyangd/meow`（6 Stars）、`kadoufall/Urban-Sound-Classification-VS`（97 Stars）

**核心方法：**
- 将音频转换为 Mel-spectrogram 或 MFCC 二维图像
- 使用 2D CNN（类似图像分类）或 1D CNN（直接在时序特征上卷积）
- 数据增强：时间拉伸、音高变换、噪声注入、SpecAugment

**代表架构：**

| 模型 | 提出者 | 核心设计 | 适用场景 |
|------|--------|----------|----------|
| Meow_Net | Yfyangd/meow | Proliferate模块+Attention | 猫叫声分类 |
| CNN-1D | hemo528/CatMeows | 直接在MFCC时序上卷积 | 猫情绪分类 |
| 标准2D CNN | CrispenGari | Mel-spectrogram + 多层卷积 | 猫狗二分类 |

**优势：**
- 当前猫狗声音识别领域最主流方案
- 训练数据需求适中（数百到数千样本即可）
- 成熟框架支持（PyTorch/torchaudio、TensorFlow）

**劣势：**
- 忽视了音频的长时序依赖
- 感受野受限，难以捕捉远距离上下文
- 对噪声环境鲁棒性有限

#### 路线三：CNN + RNN (CRNN)

**代表项目：** `ksanjeevan/crnn-audio-classification`（390 Stars）

**核心方法：**
- CNN提取局部频谱特征 → RNN/LSTM/GRU 捕捉时序依赖
- 结合卷积的局部感知和循环网络的长程记忆能力
- 常见结构：多卷积层 → 双向GRU → 全连接分类

**优势：**
- 比纯CNN更好地捕捉声音事件的时序演化
- 适合变长音频输入
- 在ESC-50、UrbanSound8K等基准上表现优异

**劣势：**
- 训练比纯CNN更慢
- RNN存在梯度消失问题（LSTM/GRU缓解但未根除）

#### 路线四：Transformer 架构

**代表项目：** `RetroCirce/HTS-Audio-Transformer`（500 Stars）、`IliaZenkov/transformer-cnn-emotion-recognition`（269 Stars）

**核心方法：**
- HTS-AT：层级Token语义音频Transformer，将频谱图切分为Patch，使用层级聚合机制
- AST (Audio Spectrogram Transformer)：直接应用ViT架构于频谱图Patch
- CNN-Transformer 并行：CNN分支捕获局部特征，Transformer分支建模全局依赖

**优势：**
- 全局感受野，天然捕捉长程依赖
- 在大规模预训练下性能优异
- 架构统一（与NLP/CV一致），便于多模态融合

**劣势：**
- 数据需求大，小数据集容易过拟合
- 推理速度慢于CNN
- 在猫狗专用项目中应用极少（尚处研究阶段）

#### 路线五：自监督预训练 + 微调

**代表项目：** `m3hrdadfi/soxan`（276 Stars，Wav2Vec）

**核心方法：**
- 在大规模无标注音频上自监督预训练（Wav2Vec 2.0、HuBERT、BEATs等）
- 在下游猫狗声音任务上微调少量标注数据
- 无需大量特定领域标注，利用通用音频知识

**优势：**
- 标签需求大幅降低
- 泛化能力强
- 代表前沿趋势，与NLP大模型路线一致

**劣势：**
- 预训练模型计算成本高
- 猫狗声音在现有预训练数据中占比低，域迁移效果待验证
- 部署推理资源需求较高

### 3.3 主流特征提取方法分析

```
原始音频波形 (.wav)
    │
    ├── 时域特征
    │   ├── 短时能量 (Short-time Energy)
    │   ├── 过零率 (Zero-crossing Rate)
    │   └── 自相关 (Autocorrelation)
    │
    ├── 频域特征
    │   ├── 频谱图 (Spectrogram) ← STFT变换
    │   ├── Mel频谱图 (Mel-spectrogram) ← Mel滤波器组
    │   ├── MFCC ← Mel频谱图 + DCT
    │   ├── Chroma ← 音高类别特征
    │   └── 频谱对比度 (Spectral Contrast)
    │
    └── 学习特征
        ├── Wav2Vec 2.0 隐层表示
        ├── VGGish (AudioSet预训练)
        ├── PANNs 嵌入
        └── CLAP 多模态嵌入
```

在猫狗声音识别项目中，**MFCC 是最广泛使用的特征**（出现于 80% 以上的专用项目），其次是 Mel-spectrogram。原因：
- MFCC 模仿人耳听觉特性，对动物声音的频谱包络有良好表示
- 维度低（通常 13-40 维），训练效率高
- librosa/torchaudio 一行代码即可提取

### 5.2 关系定义

```
                          ┌──────────────────────────┐
                          │         Dataset           │
                          └──────────┬───────────────┘
                                     │
                            TRAINED_ON (1:N)
                                     │
                          ┌──────────▼───────────────┐
                          │          Model           │
                          └──────────┬───────────────┘
                                     │
                        PREDICTS (Model → Prediction)
                                     │
┌──────────┐    PRODUCES    ┌────────▼───────┐    CONTAINS    ┌──────────────┐
│  Animal  │───────────────►│  Vocalization  │◄───────────────│ AudioSample  │
└──────────┘    (1:N)       └───────┬────────┘    (1:N)       └──────┬───────┘
                                    │                                │
                            HAS_ANNOTATION              PREDICTED_BY (1:N)
                            (1:N)                       │
                                    │               ┌───▼────────┐
                              ┌─────▼─────┐         │ Prediction  │
                              │ Annotation │         └─────────────┘
                              └────────────┘

关系详细定义:
────────────────────────────────────────────────────────────

Animal ──[PRODUCES]──► Vocalization
  基数: 1:N (一只动物可产生多次发声)
  外键: Vocalization.animal_id → Animal.animal_id

AudioSample ──[CONTAINS]──► Vocalization
  基数: 1:N (一个音频可包含多个发声事件)
  外键: Vocalization.audio_sample_id → AudioSample.audio_sample_id

Vocalization ──[HAS_ANNOTATION]──► Annotation
  基数: 1:N (一个发声事件可有多个标注)
  外键: Annotation.vocalization_id → Vocalization.vocalization_id

Annotation ──[ANNOTATES]──► AudioSample
  基数: N:1 (标注可直接关联音频样本)
  外键: Annotation.audio_sample_id → AudioSample.audio_sample_id

Model ──[TRAINED_ON]──► Dataset
  基数: N:M (多模型可用同一数据集，一个数据集可训练多模型)
  关联表: model_dataset(model_id, dataset_id, split[train/val/test])

Model ──[GENERATES]──► Prediction
  基数: 1:N (一个模型产生多个预测)
  外键: Prediction.model_id → Model.model_id

AudioSample ──[HAS_PREDICTION]──► Prediction
  基数: 1:N (一个音频可有多个模型预测)
  外键: Prediction.audio_sample_id → AudioSample.audio_sample_id

Vocalization ──[HAS_PREDICTION]──► Prediction
  基数: 1:N (一个发声事件可有多个预测)
  外键: Prediction.vocalization_id → Vocalization.vocalization_id
```

```
│  │  PostgreSQL (主库)   │   │  MinIO/S3 (对象存储)  │      │

│  │  pgvector (向量扩展) │   │  TimescaleDB (时序)   │      │

│                                                           │
└──────────────────────────────────────────────────────────┘
```

**选型理由：**

| 组件 | 选型 | 理由 |
|------|------|------|
| 主数据库 | PostgreSQL 15+ | 成熟稳定、生态丰富、支持 JSON/JSONB |
| 向量检索 | pgvector 扩展 | 与 PG 深度集成，避免多数据库运维复杂度；对于千万级向量仍可承受 |
| 对象存储 | MinIO (兼容 S3) | 音频文件、模型文件非结构化数据存储；成本低、高可用 |
| 时序数据 | TimescaleDB (PG 扩展) | 模型预测结果天然是时序数据；与 PG 统一的 SQL 接口 |
| 缓存 | Redis | 高频查询缓存、模型推理结果缓存 |

```sql

-- 动物表
CREATE TABLE animals (

    age_months       FLOAT,
    age_category     VARCHAR(20),
    weight_kg        FLOAT,
    neutered         BOOLEAN,
    name             VARCHAR(100),
    owner_id         VARCHAR(100),
    health_status    TEXT,
    metadata         JSONB DEFAULT '{}',
    registered_at    TIMESTAMPTZ DEFAULT NOW(),
    updated_at       TIMESTAMPTZ DEFAULT NOW()
);

-- 音频样本表
CREATE TABLE audio_samples (
    audio_sample_id          UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    file_path                TEXT NOT NULL,
    file_format              VARCHAR(10) NOT NULL,
    duration_seconds         FLOAT NOT NULL,
    sample_rate_hz           INTEGER NOT NULL,
    channels                 SMALLINT DEFAULT 1,
    bit_depth                SMALLINT,
    file_size_bytes          BIGINT,

    recording_environment    VARCHAR(20),

    temperature_celsius      FLOAT,

    recorded_at              TIMESTAMPTZ,
    uploaded_at              TIMESTAMPTZ DEFAULT NOW(),
    source                   VARCHAR(30),
    source_url               TEXT,
    license                  VARCHAR(100),
    audio_fingerprint        VARCHAR(128),
    checksum_sha256          VARCHAR(64),
    n_samples                BIGINT,
    metadata                 JSONB DEFAULT '{}'
);

-- 发声事件表
CREATE TABLE vocalizations (
    vocalization_id          UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    audio_sample_id          UUID NOT NULL REFERENCES audio_samples(audio_sample_id) ON DELETE CASCADE,
    animal_id                UUID REFERENCES animals(animal_id) ON DELETE SET NULL,
    start_time_seconds       FLOAT NOT NULL,
    end_time_seconds         FLOAT NOT NULL,
    duration_seconds         FLOAT GENERATED ALWAYS AS (end_time_seconds - start_time_seconds) STORED,
    vocalization_type        VARCHAR(30) NOT NULL,
    intensity_db             FLOAT,
    fundamental_frequency_hz FLOAT,
    detection_confidence     FLOAT CHECK (detection_confidence >= 0 AND detection_confidence <= 1),
    is_isolated              BOOLEAN DEFAULT TRUE,
    background_events        JSONB DEFAULT '[]',
    detection_method         VARCHAR(100),
    features_json            JSONB,
    embedding                VECTOR(512),  -- pgvector: 音频嵌入向量
    created_at               TIMESTAMPTZ DEFAULT NOW()
);

-- 标注表
CREATE TABLE annotations (
    annotation_id               UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    vocalization_id             UUID REFERENCES vocalizations(vocalization_id) ON DELETE CASCADE,
    audio_sample_id             UUID REFERENCES audio_samples(audio_sample_id) ON DELETE CASCADE,
    annotator_id                VARCHAR(100) NOT NULL,
    annotation_type             VARCHAR(30) NOT NULL,
    label                       VARCHAR(200) NOT NULL,
    label_confidence            FLOAT DEFAULT 1.0,
    label_metadata              JSONB DEFAULT '{}',
    emotion_category            VARCHAR(30),
    intent_category             VARCHAR(30),
    context                     TEXT,
    is_gold_standard            BOOLEAN DEFAULT FALSE,
    inter_annotator_agreement   FLOAT,
    annotated_at                TIMESTAMPTZ DEFAULT NOW(),
    CONSTRAINT chk_annotation_target CHECK (
        (vocalization_id IS NOT NULL) OR (audio_sample_id IS NOT NULL)
    )
);

-- 数据集表
CREATE TABLE datasets (
    dataset_id               UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    name                     VARCHAR(200) NOT NULL UNIQUE,
    version                  VARCHAR(50) DEFAULT '1.0',
    description              TEXT,
    species                  VARCHAR(10)[] NOT NULL DEFAULT '{}',
    n_samples                INTEGER DEFAULT 0,
    n_animals                INTEGER DEFAULT 0,
    n_annotations            INTEGER DEFAULT 0,
    annotation_types         VARCHAR(30)[] DEFAULT '{}',
    data_collection_method   TEXT,
    license                  VARCHAR(100),
    doi                      VARCHAR(200),
    url                      TEXT,
    paper_url                TEXT,
    created_at               TIMESTAMPTZ DEFAULT NOW()
);

-- 音频样本与数据集关联表 (N:M)
CREATE TABLE dataset_audio_samples (
    dataset_id       UUID REFERENCES datasets(dataset_id) ON DELETE CASCADE,
    audio_sample_id  UUID REFERENCES audio_samples(audio_sample_id) ON DELETE CASCADE,

    PRIMARY KEY (dataset_id, audio_sample_id)
);

-- 模型注册表
CREATE TABLE models (
    model_id               UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    name                   VARCHAR(200) NOT NULL,
    version                VARCHAR(50) NOT NULL,
    architecture           VARCHAR(50) NOT NULL,
    architecture_details   JSONB DEFAULT '{}',
    n_parameters           BIGINT,
    input_features         VARCHAR(30)[] DEFAULT '{}',
    input_sample_rate      INTEGER,
    input_duration_seconds FLOAT,
    framework              VARCHAR(30),
    training_dataset_id    UUID REFERENCES datasets(dataset_id) ON DELETE SET NULL,
    training_config        JSONB DEFAULT '{}',
    checkpoint_url         TEXT,
    model_binary_path      TEXT,
    accuracy               FLOAT,
    precision              FLOAT,
    recall                 FLOAT,
    f1_score               FLOAT,
    n_classes              INTEGER,
    class_labels           VARCHAR(100)[] DEFAULT '{}',
    inference_time_ms      FLOAT,
    model_size_mb          FLOAT,
    embedding_dim          INTEGER,     -- 输出嵌入维度

    UNIQUE(name, version)
);

-- 预测结果表 (TimescaleDB 超表)
CREATE TABLE predictions (
    prediction_id      UUID DEFAULT gen_random_uuid(),
    model_id           UUID NOT NULL REFERENCES models(model_id) ON DELETE CASCADE,

    vocalization_id    UUID REFERENCES vocalizations(vocalization_id) ON DELETE SET NULL,

    inference_time_ms  FLOAT,
    is_ensemble        BOOLEAN DEFAULT FALSE,
    ensemble_members   UUID[] DEFAULT '{}',
    predicted_at       TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    PRIMARY KEY (prediction_id, predicted_at)
);

-- 转换为 TimescaleDB 超表
SELECT create_hypertable('predictions', 'predicted_at',
```

### 6.3 关键技术决策建议

| 决策点 | 推荐方案 | 备选方案 | 决策理由 |
|--------|----------|----------|----------|
| 起步模型架构 | CNN + Mel-spectrogram | CRNN | 数据量小时CNN泛化更好，UrbanSound8K项目已验证 |
| 特征提取 | MFCC (40维) | Mel-spectrogram (128 mel bins) | 主流选择，维度低训练快，hemeo528等已验证 |
| 高级模型 | PANNs (预训练) | Wav2Vec 2.0 | PANNs在AudioSet预训练，域迁移友好；Wav2Vec偏人声 |
| 音频预处理 | 16kHz重采样 + RMS归一化 | 原始采样率 | 统一输入维度，减少计算量，满足多数模型要求 |
| 数据增强 | SpecAugment + 噪声注入 | Mixup | SpecAugment专为频谱图设计，在音频任务中广泛验证 |
| 数据库 | PostgreSQL + pgvector | MongoDB + FAISS | PostgreSQL更成熟、事务支持好、生态丰富 |
| 部署框架 | ONNX Runtime | TensorRT | ONNX跨平台、框架无关，TensorRT仅限NVIDIA |
| 标注工具 | Label Studio | 自研 | 开源成熟、支持音频标注、多标注者管理 |
