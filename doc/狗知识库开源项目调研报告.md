# 狗知识库/文档开源项目全网调研与对比报告

> 调研日期:2026-07-06 ｜ 调研方式:Dynamic Workflow 多 agent 全网搜索 + 深采 + 对抗核验
> 数据来源:GitHub API / DuckDuckGo(中英)/ HuggingFace / Kaggle / OBO Foundry / 学术数据库
> 项目总量:深采 115 个(去重)→ 真"狗知识库" 74 个(yes 54 + partial 20)｜核验 51 个(confirmed 50 / refuted 1)

---

## 0. 调研方法与防伪装执行说明

**编排**:6 维度并行搜索扇出 → 去重 → 逐项 WebFetch 深采 README/repo → 关键/存疑项独立对抗核验 → 综合。共 175 个子 agent、1031 万 token、1403 次工具调用、42 分钟。

**双轨搜索**(避免漏 0-star 文档库):① GitHub API 按 star(工具/数据集轨) ② GitHub 文档型 + DuckDuckGo 顺藤摸瓜(文档轨)。本机无 gh CLI/token,WebFetch 抓 github.com 网页不消耗 API 配额,深采并行安全。

**防伪装校验**:每个搜索/深采 agent 必须返回 `sources_fetched`(带 fetch_status success/failed),可识别是否真抓取;深采抓不到的维度强制写 "insufficient data",禁止编造。

**对抗核验**:对关键/存疑项派独立 agent 换路径重抓(releases/issues/源码目录/raw 文件),默认怀疑、尝试推翻。

**失败恢复**:Synthesize agent 触发 API 内容过滤误判失败,改由主线程从转录提取 115 个深采 + 51 个核验的结构化结果直接综合(数据见 `doc/dog_kb_extracted.json` / `doc/dog_kb_summary.md`)。

## 2. 分组详解(重点候选)

### 2.1 综合知识库 / 多组学数据库(最高价值)

**iDog — 犬类多组学综合知识库(首推)**
- URL:https://ngdc.cncb.ac.cn/idog/ ｜ 国家基因组数据中心(NGDC/CNCB/CAS)开发,NAR 2025 Vol.53 D1:D1039 发表
- 覆盖:基因组(4 参考基因组,CanFam4 含 30,653 基因)、变异(1929 现代样本 29.5M SNPs + 111 古代样本 + 145 品种特异 SNPs + 530 疾病关联)、转录组(141 BioProjects/28,145 差异基因)、单细胞(比格犬海马 105,057 细胞)、表观组、表型(897 犬病 / 3,207 G2P 对 / 482 标准品种)、本体(Dog Breed Ontology 456 词条 + Dog Disease Trait Ontology 1536 词条)、工具 13 个(含 AI 检索 DogRAG、品种图像分类 DogVC 94.5%)
- license:数据库内容"仅限学术免费使用",代码托管 GitHub/FigShare;2025 NAR 论文 CC BY-NC 开放获取
- 定位:目前**最全面、最权威的犬类综合知识库**,学术机构背书,覆盖行为/疾病/品种/表型/本体/工具全维度

**Dog10K — 国际犬类基因组协作数据库**
- URL:https://dog10k.kiz.ac.cn/ ｜ 中科院昆明动物所,NAR 2024(DOI:10.1093/nar/gkae928)
- 数据:1987 个犬科个体(324 品种/类群:1611 家犬 + 309 村犬来自 26 国 + 63 狼 + 4 郊狼)、5296 万 SNVs、8565 DNMs、单细胞 RNA(海马 105,057 + 白血病 74,067 细胞)、衰老转录组(30 狗 + 469 人)、4 基因组组装、行为/疾病维度
- 定位:与 iDog 互补的国际协作基因组门户,偏遗传/衰老/行为生物学

**Dog Aging Project (DAP)**
- URL:https://dogagingproject.org/data-access ｜ 16 star,active
- 数据:狗衰老纵向研究,每年发布(最新 2025 release,累积至 2024-12-31)
- license:**无开源 license,数据受 DUA 约束**,需通过 Terra 平台(Broad Institute)授权访问,仅限科研/非营利
- 定位:衰老/健康维度最权威,但门槛高(需申请)

### 2.5 本体 / 知识图谱

- **局限**:0 star、单作者单日 3 commit、无 license、无持续维护,课程作业级

## 5. 核验结论(对抗核验)

**总量**:51 个独立核验 → confirmed 50 / refuted 1 / uncertain 0

**证伪项(1 个)**:

| 项目 | 深采结论 | 核验结论 | 证据 |
|---|---|---|---|
| juniorrios/icomp-dog-breed | is_real=yes | **refuted / no** | 独立三角度(主页/README/文件树)核验:HF 自动转换后 label 列仅显示 "2 classes" 且预览标签全为 "0test",与 zip 文件名指向的 120 品种 Kaggle dog-breed-identification 严重矛盾,疑 HF 端标签解析异常,实际不可用作品种分类 |

**存疑项(在深采阶段标 uncertainty=true,核验后多为 confirmed 但有事实纠正)**:

1. **DogSpeak**:深采描述的"33.16 小时总时长"在 README/数据集卡均未出现(README 仅对相关 CATVD 数据集提 ~11.4h),33.16h 可能源自 ACM 论文正文,数据集卡未标注 → 核验 confirmed 但总时长存疑
2. **benjamingray44/inertial-data**:license 冲突(正文 CC BY 4.0 vs JSON-LD CC BY-ND 4.0)→ 核验 confirmed 但 license 需以 Mendeley 原始源为准
3. **Calm Hound**:免费指南背后藏 $19 付费电子书 The Calm Dog Protocol(Gumroad),深采"免费正向引导"描述未提及商业转化 → 核验 confirmed(确为狗文档站)但商业转化未披露
4. **Deep-Learning-Canine-Behavior**:深采"含数据集"易让人以为可下载,实际 data/ 目录只有 Permission-to-Use-Data.md,README 明确"dataset available upon request"需向作者申请 → 核验 confirmed 但数据不公开
5. **ziya07/Dog Behavior Monitoring**:数据为 simulated 合成(仅 1 只狗/60s/50Hz/~3000 条,姿态"随机选取"后规则推导标签),非真实观测 → 核验 confirmed 但合成数据
6. **lurnake/dog-breed-traits-data**:相似度评分由 Gemini-2.0-Pro 直接打分,嵌入用 OpenAI text-embedding-3-large,**AI 合成数据非专家策展** → 核验 confirmed
7. **Paws&Tales**:仓库仅 Next.js 代码,文章在 MySQL + Tair 缓存,**知识内容不在仓库不可离线审计** → 核验 confirmed(partial)但作为开源知识库不可复用
8. **BreedFinder**:activity 深采标 unknown,核验推翻为 active(672 commits);GitHub API 无 token 403 无法精确取 pushed_at
9. **Movement Sensor Dataset**:activity 深采标 stale 被核验推翻
10. **Meta-Album DOG**:star 字段推理有误(非 GitHub repo 无 star 概念),核验纠正

**核验价值**:对抗核验抓出 1 个真幻觉(证伪) + 10 处事实纠正/存疑标注,证明防伪装设计见效——即使学术/数据集领域仍存在标签解析异常、license 冲突、合成数据冒充真实观测、商业转化未披露等需显式标注的问题。

## 7. 局限与缺口

### 已覆盖
- breed 品种:充分(图像/百科/本体/结构化/API 全有)
- behavior 行为:数据集充分(叫声/情绪/姿态/活动)
- 综合/多组学:iDog/Dog10K/DAP 学术级权威
- 本体:有技术栈样本

### 仍薄弱/未覆盖的缺口

1. **疾病/兽医方向最薄弱**:无系统化犬疾病知识库,仅 bulldogs(单犬种单病种)+ VetDataHub(多物种目录)+ 若干表格/预测代码。缺犬病循证知识库、犬药理学库、犬临床决策支持库
2. **饲养/营养专题几乎空白**:无专门犬营养/喂养知识库,Paws&Tales 等内容站文章不在仓库
3. **训练专题极薄弱**:无系统训练知识库,Calm Hound 仅分离焦虑且藏付费内容
4. **中文开源项目近乎空白**:遛养派(19up.com)是闭源商业平台;Dog Translator 是商业站点;无中文开源犬知识库
5. **本体规模小**:除 iDog 内置本体与 VBO/MP 外,Dog Knowledge Graph/Stanford-Dogs-OWL/Dog Breed Ontology 均为学生作业级,0 star 无 license
6. **行为知识文本缺失**:behavior 方向多为 ML 训练数据(音频/图像/IMU),缺"狗行为学知识图谱/行为解读文本库"
7. **数据集 license 不规范**:大量 Unknown/未声明/冲突,Kaggle 竞赛规则非标准开源许可
8. **HF 端标签解析风险**:juniorrios/icomp-dog-breed 证伪案显示 HF 自动转换 imagefolder→Parquet 可能损坏标签,使用前必须核验

### 方法局限
- 本机无 gh CLI/token,GitHub API 未认证 60 req/h,部分仓库 pushed_at/license 未能精确抓取(标 insufficient data)
- Kaggle/HF 纯 JS 渲染,WebFetch 仅得标题,改用 API/fetch raw HTML + JSON-LD 元数据绕过
- Synthesize agent 触发 API 内容过滤误判失败,终稿由主线程从结构化数据综合(已保留全部深采+核验证据)
