## 2. 重点新特性详解

### 2.1 跨 Session 通信：SendMessage + ListAgents + @提及（v2.1.224 / v2.1.232）★ 重度 agent 用户必看

**含义**：
- v2.1.224 新增 `SendMessage` 和 `ListAgents` 工具，同一台机器上的 Claude Code session 可互相发现并通信（macOS/Linux）
- v2.1.232 加入 `@` 提及：在 prompt 输入 `@` 可点名另一个 session 直接发消息；v2.1.225 扩展到跨机器 Remote Control session

**好处**：多个 Claude session 之间可协调工作，不再各自为战。

**与本机关系**：✅ 本机开启 `CLAUDE_CODE_EXPERIMENTAL_AGENT_TEAMS` 且重度使用后台 agent。跨 session 通信是 agent 协作的基础设施，升级后可配合 agent teams 实现更复杂的多 session 编排。Windows 上在 v2.1.239 也已支持。

### 2.2 子 Agent 200/会话上限移除 + fork 默认开启（v2.1.224 / v2.1.232）★

**含义**：
- v2.1.224 **移除了每会话 200 个子 agent 的生成上限**（并发与嵌套深度限制保留）
- v2.1.232 `subagent_type: "fork"` 默认开启：fork 子 agent 继承完整对话与 prompt cache；非 teammate 的 agent 在交互 session 中默认后台运行

**好处**：长 session 不再被 200 上限卡住；fork 子 agent 可直接利用 prompt cache 省钱。

**与本机关系**：✅ 本机重度 agent 用户。200 上限移除对长 session 编排是解放；fork 默认开启意味着子 agent 自动享受 prompt cache（v2.1.243 的 `promptCacheTtl` 可精细控制主对话 1h vs 子 agent 5min）。

### 2.3 `/cd` 即时生效（v2.1.246）★

**含义**：`/cd` 切换目录后，新目录的项目设置、hooks、`.mcp.json`、skills、agents **立即生效**，不再需要 `--resume`。

**与本机关系**：✅ 本机多项目切换频繁。此前 `/cd` 后 hooks 和 skills 不即时生效是已知痛点，升级后此问题消除。

### 2.4 `ANTHROPIC_DEFAULT_MODEL` 环境变量（v2.1.236）

**含义**：新增 `ANTHROPIC_DEFAULT_MODEL` 环境变量，设定新 session 的默认模型；`/model` 选择后仍会覆盖并持久化（与 `ANTHROPIC_MODEL` 的区别：后者同时控制 `/model` 行为）。

**与本机关系**：⚠️ 本机已通过 `ANTHROPIC_MODEL` 等变量直接设定模型（`qwen3.7-plus[1M]`），新增的 `ANTHROPIC_DEFAULT_MODEL` 在本机代理环境下意义有限，知道有即可。

### 2.5 "简洁"输出风格（v2.1.237）

**含义**：内置 "Concise" 输出风格——Claude 直接给结果，跳过铺垫和叙述，工作仍然同样深入。在 `/config` 的 Output style 里选择。

**与本机关系**：✅ 本机 `effortLevel: xhigh`，输出风格切换为 Concise 可进一步减少 token 消耗与等待时间，值得一试。

### 2.6 `modelPicker` 设置（v2.1.243）

**含义**：`modelPicker` 设置可定制 `/model` 选择器显示的模型列表（支持任意 ID 拼写，含 Vertex/Bedrock ID），按指定顺序和标签排列。

**与本机关系**：⚠️ 本机走代理，`/model` 选择器里的官方模型实际不可用。此设置对代理环境价值有限。

### 2.7 `promptCacheTtl` 设置（v2.1.243）

**含义**：可分别为 API key 和云 provider 用户设定主对话 prompt cache 的 TTL（如 1 小时）与子 agent 的 TTL（如 5 分钟）。

**与本机关系**：⚠️ 本机走阿里云代理，prompt caching 行为取决于代理侧实现。若代理透传缓存语义，此设置可用于精细控制缓存成本。

### 2.8 `SendFeedback` 工具 + `/claude-api cost-optimize`（v2.1.247）

**含义**：
- `SendFeedback`：session 中遇到问题时，Claude 可草拟反馈报告供你从 `/feedback` 审阅发送（`feedbackDrafts` 设置可关）
- `/claude-api cost-optimize`：分析项目 Claude API 消费，逐项走缓存/token 卫生/batch/effort/模型选择等成本杠杆

**与本机关系**：⚠️ `SendFeedback` 面向官方 API 反馈渠道，本机代理环境用处有限。`/claude-api cost-optimize` 面向 Anthropic SDK 项目，非本机场景。

### 2.9 `/usage` 新增 Loops 分析（v2.1.243）

**含义**：`/usage` 新增 Loops 分类视图——每 loop 运行次数、总 token、每轮 token、最后运行时间。失控或高频的 `/loop` 任务一目了然。

**与本机关系**：✅ 本机用 workflow 编排多，若搭配 `/loop` 使用，此视图有助于发现 token 浪费。

### 2.10 自托管 Runner（v2.1.224）

**含义**：`claude self-hosted-runner` 将自有机器/容器变成 Claude Code Web/Mobile/Desktop session 的运行环境，Team 和 Enterprise 计划可用。

**与本机关系**：⚠️ 本机非 Team/Enterprise 管理部署，此特性暂无使用场景。

### 2.11 其他值得关注的新特性

- **`spellcheck` 设置**（v2.1.235）：prompt 输入实时拼写检查，依赖 `aspell`/`hunspell`/`ispell`。⚠️ 中文环境用处不大
- **`keybindingFlavor` 设置**（v2.1.238）：设为 `"readline"` 可使 Ctrl+W 在 prompt 中删除到前一空白（类 Bash 行为）
- **GitLab MR 徽章**（v2.1.233/234）：footer 显示 GitLab MR !N 状态。⚠️ 本机用 GitHub
- **`CLAUDE_CODE_WEBFETCH_CACHE_TTL_MS`**（v2.1.233）：WebFetch URL 缓存 TTL 可调（默认仍 15 分钟）。✅ 本机使用 WebFetch，可调大以减少重复抓取
- **插件 `headersHelper`**（v2.1.238）：URL 市场插件可运行命令获取短效 HTTP header（如 token），仅安装/更新时运行
- **`archive` 插件源**（v2.1.224）：从 HTTPS zip 安装插件，支持 SHA-256 锁定
- **Write 工具放宽**（v2.1.228）：新模型可覆盖未读过的已有文件（与 Edit 工具规则一致）
- **非交互 session 自动续接**（v2.1.246）：`-p`、SDK、云 session 中因服务器错误/连接中断/停滞被截断的响应自动续接，不再报错结束

## 3. 行为变化（影响使用习惯）

### 3.1 子 Agent fork 默认开启（v2.1.232）★

**变化**：`subagent_type: "fork"` 成为默认；fork 子 agent 继承完整对话历史与 prompt cache。非 teammate 的 agent 在交互 session 中默认后台运行。

**影响**：✅ 子 agent 自动享受 prompt cache 可显著降低成本。后台运行意味着 agent 结果不再原地等待。

### 3.2 每会话 200 子 agent 上限移除（v2.1.224）

**变化**：不再有每 session 200 个子 agent 的生成总数限制（并发与嵌套深度限制保留）。

**影响**：✅ 长 session 不再被上限阻断。

### 3.3 Todo 工具从新模型移除（v2.1.233）

**变化**：TaskCreate/Get/Update/List、TodoWrite 工具在 Opus 4.8、Sonnet 5、Fable 5、Mythos 5 及更新模型上**不再可用**；设 `CLAUDE_CODE_ENABLE_TODO_TOOLS=1` 可恢复。

**影响**：⚠️ 本机若使用这些模型 + todo 工具，需添加该环境变量恢复。

### 3.4 `/code-review` 高级别审查后台化（v2.1.232）

**变化**：`/code-review` 在 high/xhigh/max effort 下以后台 agent 方式运行（与低级别对齐）。

**影响**：✅ 所有级别的审查都不再占主上下文。

### 3.5 `/cd` 即时生效（v2.1.246）★

**变化**：`/cd` 后新目录的 hooks、skills、agents、`.mcp.json` 等立即生效（不再需 `--resume`）。

**影响**：✅ 多项目切换效率提升。

### 3.6 自动模式扩展（v2.1.236 / v2.1.246）

**变化**：
- v2.1.236：Bedrock/Vertex/Foundry 及遥测禁用环境下，自动模式分类器使用与 Claude API 相同的默认值（含严重度评分）
- v2.1.246：`/code-review` 在 Bedrock/Vertex/Foundry 与遥测禁用环境下也可由 Claude 自行启动；`/model`、`/fast`、`/effort` 同理立即执行不再排队

**影响**：⚠️ 本机走代理，不直接适用，但代理若透传 Bedrock/Vertex 标识可能受益。

### 3.7 其他小变化

- **Sonnet 5 auto-compact 窗口扩大到完整 1M**（v2.1.247）：约 967K token 时才触发压缩（此前约 934K）。⚠️ 本机模型非 Sonnet 5，但若代理侧报告为 Sonnet 5 则受益
- **跨 session peer 消息默认折叠**（v2.1.247）：单行预览，Ctrl+O 展开
- **`/model`、`/fast`、`/effort` 立即执行**（v2.1.243）：Bedrock/Vertex/Foundry 及遥测禁用环境下不再排队到 turn 结束
- **`/permissions` 可在 Claude 工作时打开**（v2.1.234）：规则变更对当前 turn 剩余部分生效
- **`/add-dir` 可在 Claude 工作时使用**（v2.1.234）
- **全屏渲染器不再双击 Ctrl+L/Cmd+K 触发 `/clear`**（v2.1.238）
- **`claude mcp list` 禁用 server 显示为 `⊘ Disabled`**（v2.1.238）：不再为健康检查连接它们
- **沙箱 Bash prompt 不再列出允许的网络主机**（v2.1.243）：Claude 会尝试请求，用户可审批新主机
- **反馈调查 transcript 分享现也上传 system prompt 与工具定义**（v2.1.224）：密钥脱敏，字段过大时优先丢弃

## 5. 重要 bug 修复（挑本机有感项）

### 5.1 PowerShell 权限绕过修复（v2.1.232）★★ 安全修复

**问题**：变量写入参数可静默覆盖 `$PSDefaultParameterValues`，重定向后续命令的文件访问。

**修复**：阻止该覆盖路径。

**与本机关系**：✅✅ 本机主 shell 为 PowerShell 5.1，且开 `CLAUDE_CODE_USE_POWERSHELL_TOOL=1`。这是安全修复，升级必要。

### 5.2 长 session 内存泄漏系列修复（v2.1.238 / v2.1.243 / v2.1.246 / v2.1.247）★

**修复**：
- v2.1.238：长交互 session 无界内存增长——子 agent 工具结果在离开近期显示窗口后释放
- v2.1.243：原生构建内存优化——按需加载代码（每 session 减少约 40-70 MB）；长时间 session 峰值内存改善（堆增长时提前 GC）
- v2.1.246：全屏/Ctrl+O 转录视图内存随 session 长度增长——每行不再保留全 session 工具查找副本
- v2.1.247：hook 或后台任务输出文件无法写入时的无界内存增长——现已限制并标注丢失位置

**与本机关系**：✅ 本机长 session + 多 agent + 多 MCP，直接受益。

### 5.3 启动性能提升（v2.1.243 / v2.1.238）★

**修复/改进**：
- v2.1.243：sandbox 与 MCP 启动不再阻塞首帧；裸启动跳过子命令注册；workflow 发现、设置、信任库工作更轻量
- v2.1.243：原生安装/自动更新下载大小——zstd 压缩（Linux x64 从约 340 MB 降至约 75 MB）
- v2.1.238：裸 `claude` 在 macOS 启动更快；自动更新检查延迟到启动后约 10 秒

**与本机关系**：✅ 启动速度提升在所有环境可感知。

### 5.4 Bash 工具延迟优化（v2.1.246）

**修复**：Bash 快照函数回放不再使用 base64 子 shell，降低 zsh 环境延迟。

**与本机关系**：⚠️ 本机 PowerShell 主 shell，此优化主要针对 zsh。但 Bash 工具仍会用于 Git Bash 等场景。

### 5.5 全屏转录严重卡顿修复（v2.1.246）★

**问题**：diff 中含极长单行（如 base64 字符串）时转录严重卡顿。

**修复**：此类行截断渲染并标注。

**与本机关系**：✅ 本机常处理大文件/大输出，直接受益。

### 5.6 子 agent 首个模型 404 时不再直接死亡（v2.1.247）★

**问题**：子 agent 首次调用模型返回 404 时直接终止。

**修复**：改用 session 的 fallback 模型链，返回父 agent 的错误含类型、状态码、请求 ID 与模型。

**与本机关系**：✅ 本机代理环境下模型 ID 非标准（`qwen3.7-plus[1M]`），404 场景更常见。此修复直接提升子 agent 稳定性。

### 5.7 Hook/后台任务大输出溢出对话修复（v2.1.247）★

**问题**：hook 或后台 agent 打印 MB 级错误输出可溢出对话，session 卡在 "Prompt is too long"。

**修复**：防止溢出。

**与本机关系**：✅ 本机 hooks 多（notifications、gateguard 等），直接受益。

### 5.8 后台 session 打开失败修复（v2.1.246）★

**问题**：后台 session 在以下场景打开需等 45 秒或报 EACCES：
- 启动目录被删除
- 机器休眠后唤醒
- 另一进程正在重装 npm 包

**修复**：以上场景快速失败或重试。

**与本机关系**：✅ 本机 Windows + 重度后台 agent 用户，机器休眠场景直接相关。

### 5.9 动态 workflow 左箭头/`/background` 重启已完成子 agent 修复（v2.1.246）★

**问题**：动态 workflow 进行中按 ← 或运行 `/background` 会重启已完成的子 agent。

## 7. 升级建议

### 7.1 是否升级

**建议升级**。2.1.223 → 2.1.247 对本机有明确高价值项：

1. **PowerShell 权限绕过修复**（v2.1.232）——安全修复，本机主 shell 即 PS 5.1
2. **长 session 内存泄漏系列修复**（v2.1.238/243/246/247）——本机长 session + 多 agent 全中
3. **网关 prompt caching 修复**（v2.1.237）——本机走自定义 BASE_URL
4. **子 agent 稳定性**：200 上限移除（v2.1.224）、404 回退（v2.1.247）、fork 默认开启（v2.1.232）——重度 agent 用户核心受益
5. **`/cd` 即时生效**（v2.1.246）——多项目切换痛点消除
6. **Windows 后台 session 修复**（v2.1.246）——休眠唤醒场景

Sonnet 5 / Opus 5 新模型相关更新对本机（代理环境）无直接效果，不构成障碍。

### 7.2 升级方法（手动，因黑名单不自动更新）

```bash
# 本机 DISABLE_AUTOUPDATER=1，daemon 不会自动更新 CLI，需手动：
npm install -g @anthropic-ai/claude-code@2.1.247

# 验证
claude --version   # 应显示 2.1.247

# 如需回滚到当前版本：
npm install -g @anthropic-ai/claude-code@2.1.223
```

### 7.3 升级后必做

1. **重启 Claude Code daemon**，使新版本生效
2. 检查 `~/.claude/settings.json` env 段：`DISABLE_AUTOUPDATER=1` 保留
3. 跑一次 `/doctor` 自检环境
4. 若使用 Todo 工具且切到了新模型，添加 `CLAUDE_CODE_ENABLE_TODO_TOOLS=1`
5. 考虑尝试 "简洁" 输出风格（`/config` → Output style → Concise）
6. update-all 技能黑名单保持不动（`@anthropic-ai/claude-code` 不自动更新是本机既定策略）

### 7.4 不升级的风险

- PowerShell 5.1 权限检查绕过暴露（v2.1.232 安全修复）
- 长 session 内存泄漏持续存在，卡顿加剧（v2.1.238/243/246/247 修复）
- 网关 prompt caching 不工作，token 成本偏高（v2.1.237 修复）
- 子 agent 仍受 200 上限约束，长 session 编排被阻断
- 后台 session 休眠唤醒后打开慢或失败（v2.1.246 修复）
- `/cd` 后 hooks/skills 不即时生效，多项目切换不便
- auto mode 在 `CLAUDE_CODE_ATTRIBUTION_HEADER=0` 下仍每工具失败（v2.1.229 修复）
