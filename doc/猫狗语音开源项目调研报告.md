## 4. 重点项目详评

### CrispenGari/animal-sound-classification（推荐起点）
真正的猫狗声音二分类，提供 REST 推理 API（POST /classify，端口 3001）。技术栈：PyTorch + torchaudio 的 CNN，权重文件 cats-dogs-sound-cnn.pt。数据：未命名（audios/ 目录，来源/许可不明）。准确率：test/val 90.7%、train 93.5%，含分类报告与混淆矩阵。运行：`virtualenv venv && pip install -r requirements.txt && python api/app.py`，curl/Postman/JS fetch 示例齐全。优点：MIT 许可、API 文档完整、唯一真正猫狗二分类+可跑 REST；缺点是 2022 年后未维护、数据来源不明、端口硬编码、99.8% 是 notebook。

### lincolnhard/dog-bark-detector（最高星，狗叫检测）
从频谱图检测狗叫（darknet CNN 二分类：狗叫 vs 非狗叫），仅狗不含猫。技术栈：Joseph Redmon 的 darknet + 自定义 cfg/dogbark.cfg，C/C++ 主体 + Python 预处理。数据：UrbanSound（训练+测试）、Freiburg 106（负样本）、ESC-50（仅测泛化）。准确率：UrbanSound top-1 ~95%、ESC-50 ~80%。运行：preprocessing.py → make → ./create_spectrogram → ./darknet classifier train；推理用 classification_from_file / classification_from_mic。优点：星最高、提供训练权重+实时麦克风推理；缺点：无 LICENSE（不可直接复用）、约 2018 年后未维护、需改 darknet 源码（args.type 改 OLD_CLASSIFICATION_DATA）搭建 hacky、仅 5 次提交。

### SolomonGithu/tinyml_dog_bark_and_howl_classification（边缘部署）
TinyML 可穿戴设备，区分狗 bark 与 howl，部署于 XIAO ESP32S3。技术栈：Edge Impulse 平台导出 Arduino 库 + 两个 .ino 推理脚本（串口打印 / SSD1306 OLED 显示），附 3D 打印外壳。数据：ElevenLabs 合成音频（非真实采集）。准确率：未报告。运行：需 Arduino IDE + Edge Impulse 库 + XIAO ESP32S3 硬件。优点：MIT 许可、边缘端可穿戴参考完整；缺点：用合成数据训练、真实狗叫泛化存疑、未报告架构与指标。

### shruti353/AI-Based-Cat-Emotion-...（现代预训练方案）
猫情绪识别（声称面部+声音，实际仅实现音频侧）。技术栈：YAMNet（tfhub google/yamnet/1）提取 1024 维音频嵌入 + SVM（sklearn SVC RBF）多分类，FastAPI 推理服务（/predict、/health）。数据：本地自采 augmented .mp3（非公开基准）。准确率：未硬编码，运行时 train_audio.py 输出 classification_report。运行：`pip install fastapi uvicorn librosa tensorflow tensorflow-hub scikit-learn joblib` → `uvicorn main:app --port 8000`；推理前先训练生成 yamnet_svm.pkl。优点：用预训练 YAMNet 特征（比从头训 CNN 更稳）、FastAPI 现代化；缺点：README 极简、无 license、CORS 配置宽松（*+credentials）、面部模块缺失。

### moh12950/Cat-VS-Dog-Detection（真猫狗二分类，但不可直接跑）
区分狗吠与猫喵的 Sequential CNN 二分类。技术栈：Keras Sequential（Conv2D 16→32→64 + GAP + Dense，~27.5k 参数），输入为 tf.signal.stft 对数频谱图，配 EarlyStopping+ReduceLROnPlateau。数据：自采 210 条本地 .wav（125 猫+85 狗），硬编码 Windows 路径。准确率：val_accuracy epoch6=0.8571，但日志在 epoch10 被截断。运行：仅一个 notebook，无 requirements、无权重、无推理脚本、路径不可移植。优点：明确猫狗二分类、架构清晰；缺点：无 license、0 star、硬编码路径无法复现、未保存权重、注释仅阿拉伯语。

## 5. 存疑与未通过核验项目

### unverified（1 个）
- **jovan-stojanovic/Animal-sound-recognition**（35 stars，MIT）：仓库真实，基于 PANNs 的 CNN14/ResNet38/Wavegram-Logmel-CNN，用 Google AudioSet 动物声音类别训练，mAP 0.439/0.551/0.561。判 unverified 原因：README 自身不提猫狗，猫狗关联仅能通过 AudioSet ontology（已知含 Cat/Dog/Meow/Bark）间接推断；项目明确定位为通用动物声音分类器，非猫狗专属识别器。若要猫狗专用须自行从 AudioSet 筛选类别，非仓库现成能力。建议：可作可筛选类别的通用底座，不应直接当猫狗项目收录。

### refuted（6 个）
- **aqibsaeed/Urban-Sound-Classification**（521 stars）：UrbanSound8K 城市环境 10 类声音分类，dog_bark 仅 10 类之一，README 全文无 cat/dog/pet，主题不符。
- **ksanjeevan/crnn-audio-classification**（391 stars）：CRNN+PyTorch+UrbanSound8K，同上，10 类城市声音，非猫狗专属。
- **josafatburmeister/BirdSongIdentification**（29 stars）：鸟类鸣叫识别（Xeno-Canto+NIPS4BPlus，10 鸟种），实为鸟类项目，全程无猫狗。
- **lina130/AI_cat**（3 stars）：ESP32 仿生机器猫，audio 指人机语音交互（麦克风采人声→百度 ASR→NLP 情感→舵机回应），非识别猫狗叫声，无狗成分。
- **seaika007/cat-emotion-dataset**（0 stars）：README 声称含图像+音频，实际仓库 0 个音频文件，纯 ResNet 图像分类（Roboflow 导出 .jpg），audio 为未兑现的虚假声明。
- **yeyupiaoling/AudioClassification-Pytorch**（null stars）：基于 Pytorch 的通用声音分类系统，"狗叫声"是 UrbanSound8K 10 类之一，猫完全未出现，非猫狗项目。

## 7. 选型建议

### 想快速跑通
首选 **HuggingFace 模型 dima806/cat_dog_sounds_classification**（Apache-2.0，一行 pipeline 即可推理，唯一有完整 model card 的猫狗声音模型）。若要 GitHub 代码，选 **CrispenGari/animal-sound-classification**（MIT、REST API 文档齐全、90.7% 准确率），但需注意 2022 年依赖版本兼容性。

### 想二次开发
推荐 **shruti353/AI-Based-Cat-Emotion-...** 的 YAMNet+SVM 方案（用预训练 YAMNet 提特征比从头训稳，FastAPI 接口现代），或 **jovan-stojanovic/Animal-sound-recognition**（unverified，但 PANNs CNN14/ResNet38 是学术界成熟方法，可在 AudioSet 上筛选猫狗类别二次开发）。数据建议用 **Wolfram Audio-Cats-and-Dogs**（164猫/113狗）或 Kaggle cats-vs-dogs-audio-classification。

### 想上生产
**当前无一个 confirmed 仓库达到生产级**（星数普遍极低、多数无 license、数据集来源不明或自采极小）。建议自建：用 wav2vec2/HuBERT 预训练骨干（参考 dima806 模型）+ 大规模公开数据（BarkMeowDB + CatMeows + DogSpeak + Audio-Cats-and-Dogs 合并）+ 标准化评估（mAP/top-1）+ Apache-2.0/MIT 许可。边缘端可参考 SolomonGithu 的 Edge Impulse 方案但须换真实采集数据。
