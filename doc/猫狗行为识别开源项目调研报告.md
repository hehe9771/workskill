# 猫狗行为识别开源项目调研报告

## 1. 检索方法与执行说明

本调研采用多 agent 全网搜索 + 逐仓库深采 + 对抗核验的三段式流程，全程规避本机无 gh CLI 的 60/h API 限速问题。

- **检索阶段**：8 个角度并行 WebFetch 打 DuckDuckGo HTML 与 GitHub 网页搜索（搜索角度覆盖：cat behavior recognition / dog activity recognition / pet pose estimation / animal action dataset / wearable sensor pet / video action recognition animal / animal behavior deep learning / 宠物行为识别中文）。本机无 gh CLI，故全部走网页抓取，规避 GitHub REST API 60/h 限速。
- **去重与候选池**：搜索结果去重后形成 55 个候选仓库。
- **深采阶段**：对 55 个仓库逐个 pipeline 深采，抽取关键声明字段（star/license/语言/物种/模态/模型架构/行为类别/数据集/推理就绪性/训练代码/硬件目标/优缺点），每条字段带 source_url。
- **对抗核验阶段**：抽取 12 条关键声明做独立对抗核验，结果 **confirmed 12 / refuted 0 / uncertain 0**。
- **防伪装执行校验**：每条数据均带 source_url；fetch 失败字段如实标注 "insufficient data"，不编造精度数字、star 数或行为类别。

## 4. 重点项目深度对比

按"宠物行为识别"相关性与工程质量，选取 8 个项目分维度对比。

### 4.1 [deeplabcut/deeplabcut](https://github.com/deeplabcut/deeplabcut)
- **数据集**：SuperAnimal-Quadruped（Zenodo 10.5281/zenodo.10619172）、SuperAnimal-TopViewMouse、AP-10K、DLC-openfield。提供 DOI 链接。
- **模型架构**：ResNet-50/101、HRNet-W32/W48、RTMPose(s/m/x)、MobileNetV2、EfficientNet、DLCRNet；PyTorch 后端（v3.0 主推），TF 后端 v3.2 计划弃用；3D 多相机三角测量。
- **精度**：未在 README 给出统一精度数字（依 backbone 与数据集而异）。
- **部署**：desktop（GUI）+ server/GPU（CUDA）+ edge（DLC-live 实时包）+ Colab + Docker；无 mobile。
- **可复现性**：高。完整工作流（标注→生成训练集→训练→分析→导出），权重经 API/HuggingFace 拉取，Model Zoo 完善。
- **活跃度**：5.7k star，v3.0.0 于 2026-05 发布，持续维护。
- **文档质量**：极高。官方文档、论文、教程、社区生态完整。
- **关键缺口**：核心是 pose estimation 不是 behavior classification，不输出 sitting/running/barking 等行为标签，需用户从关键点轨迹自行派生行为；预训练权重 research-only（非商业）。

### 4.2 [sutdcv/Animal-Kingdom](https://github.com/sutdcv/animal-kingdom)
- **数据集**：Animal Kingdom（CVPR2022），850 物种、140 行为、30K AR 序列、33K pose 帧、50h 视频接地；Google Form 审批下载。
- **模型架构**：SlowFast（full PySlowFast）、I3D、X3D、CARe（自研）、HRNet/HRNet-DARK、LGI、VSLNet。
- **精度**：README 未给出统一基线表（需查论文）。
- **部署**：server/GPU 训练；无 edge/mobile/ONNX export。
- **可复现性**：中。PySlowFast 全栈交付（train_net/test_net/run_net/demo_net），但数据集审批门槛、无 Animal-Kingdom 微调权重（MODEL_ZOO 仅 Kinetics/AVA/ImageNet 通用 backbone）。
- **活跃度**：164 star，最后实质更新 2024-12。
- **文档质量**：中。三任务各有 README，但 140 类未在 README 枚举（藏于 AR_metadata.xlsx）。
- **关键缺口**：非宠物专用（850 物种通用），无 repo 级 LICENSE，无 edge 部署，数据集需人工审批。

### 4.3 [makejian/pet-behavior-recognition](https://github.com/makejian/pet-behavior-recognition)
- **数据集**：AP10K（17 关键点猫 pose 公开数据集，作预训练）+ 自采猫数据（Label Studio 标注 27 关键点，本地 data/annotations/*.json）。无数据下载 URL。
- **模型架构**：多阶段 pipeline：YOLOv8n/YOLO11n 检测 → ByteTrack/BoT-SORT 跟踪 → RTMPose top-down 2D pose（AP10K 17 点或自定义 27 点）→ OneEuro 平滑 → **规则式 MVP 行为分类器**（非学习型时序模型）。
- **精度**：README 未报告 mAP/行为准确率（规则式，无量化指标）。
- **部署**：CLI（run.py）+ Streamlit UI（app.py）；无 export.py、无 ONNX/TensorRT、无 edge 适配。
- **可复现性**：中。训练代码齐全（train_pose.py/train_detector.py/convert_labelstudio_to_coco.py），YOLO 权重已提交（yolo11n.pt/yolov8n.pt）；但 RTMPose checkpoint 未提交（pretrained/rtmpose 空），需外部下载；自采 27 点数据未公开。
- **活跃度**：1 star，2026-05 单次 commit。
- **文档质量**：较高。中文使用手册，模块化 src/ 布局清晰，per-frame per-cat JSON 输出结构化。
- **关键缺口**：行为分类是规则式 MVP（无 3D-CNN/SlowFast/TimeSformer/LSTM），无量化精度，无 LICENSE，pose checkpoint 缺失。

### 4.4 [Christalwu1110/pawtellige](https://github.com/Christalwu1110/pawtellige)
