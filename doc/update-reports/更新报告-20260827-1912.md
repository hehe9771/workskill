## 4. 功能差异与新增功能详解

### 4.1 git/gstack 1.60.1.0 → 1.69.0.0 ★★

**变化内容：** "silent-failure wave" — 修复了 6 个"工具报告成功但实际什么都没做或做了错事"的故障模式，吸收 5 个社区 PR。（证据：`evidence/gstack-changelog.md` [1.69.0.0] 段，1411 行）

核心修复：
- `gstack-evidence run` 在含 `.env`/`.env.local` 的仓库中，bun 自动注入环境变量导致子进程环境与 CI 不一致 → value-equality scrub + names-only warning
- `./setup --host slate` 静默 exit 0 但什么都没装 → 解释 Slate 不支持 + 未来未接受的主机 exit 1
- `land-and-deploy` merge recovery 的 `--delete-branch` 半 silently dropped → ls-remote reconciliation
- orphaned skill dirs 清理结构性地找不到 → destination scan + dangling-symlink aware
- heredoc ≥512B 在 Homebrew bash 5.2+ 死锁（macOS 512-byte pipe buffer）→ BASH_COMPAT=50 guard

**对本机影响：** ✅ 直接受益 — gstack-evidence 不再被 .env 污染、setup 不会静默失败、merge recovery 可靠。

**用法举例：** `gstack-evidence run` 现在会 scrub bun 从 .env 注入的变量（`GSTACK_EVIDENCE_KEEP_DOTENV=1` 可 opt-out）；`./setup --host slate` 会解释不支持原因而非静默成功。

### 4.2 uv/specify-cli 0.15.3.dev0 → 1.0.2.dev0 ★★

**用法举例：** 无新增可举例项（specify-cli 无 changelog，用法待验证）。Compare 链接：https://github.com/github/spec-kit/compare/03d71b33...241d9163

### 4.3 plugin/ecc 2.1.0 → 2.2.0 ★★

**变化内容：**（证据：`evidence/ecc-changelog.md` Unreleased 段）

- **Default MCP connector set 缩减为单个 `chrome-devtools`**：之前默认的 6 个 connector（github, context7, exa, memory, playwright, sequential-thinking）在 June 2026 audit 后退役，改由 skills wrapping CLIs/REST APIs 替代（github-ops, documentation-lookup, exa-search, e2e skills）或 harness-native features（memory, extended thinking, web search）。所有 6 个仍可通过 `mcp-configs/mcp-servers.json` opt-in。
- `ecc memory` writes 和 `--body-file` reads 在 Windows Node 22.12-22.16 和 24.0-24.1 下失败（libuv `stat()` 未设 volume serial → memory vault TOCTOU guard 拒绝所有操作）→ guard 改用 `BigInt` values，不再依赖运行时补丁级别。

**对本机影响：** ★★ 重大行为变化 — MCP connector 策略变更意味着新建项目不再自动配置 github/context7/exa 等 MCP server，需要显式 opt-in。Windows memory vault 修复直接解决本机 Node 22+ 环境下的 memory 操作问题。

**用法举例：** 如需恢复旧 connector 行为，在项目的 `mcp-configs/mcp-servers.json` 中显式添加。`ecc memory` 在 Windows Node 22+ 下不再报错。

### 4.4 plugin/superpowers 6.2.0 → 6.3.0

**变化内容：**（证据：`evidence/superpowers-release.md` v6.3.0 段）

**对本机影响：** ✅ 直接受益 — worktree 不再丢未跟踪文件、brainstorming 对小任务更轻量。

**用法举例：** 小功能请求触发 brainstorming 时不再走完整的 spec+plan 双文档流程。
