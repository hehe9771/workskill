## 6. 失败项与修复建议

### 6.1 E1 ECC 同步首试失败（已当场修复 ✅）

**现象**（错误摘录，截自 `~/.claude/update-evidence/20260917-2259/errors/E1.err` 原文）：
```
Error: This install would enable ECC's automatic hook runtime, which can:
  1. Automatically format or otherwise modify project source files.
  2. Rewrite requested commands and start, replace, or terminate processes.
  3. Send transcript-derived conversation text to an external LLM.
  ...
Confirm with --enable-hooks to install it, or --no-hooks to install everything else without the hook runtime.
```

**根因判断**：ECC 2.2.1 上游新增 hooks 安全门控——`install.sh` 不再默认启用自动 hook 运行时，旧命令行（`--profile full` 无 hooks 选项）被拒绝退出 1。非安装损坏，是上游行为变化（★★，§4.4）。

**修复命令**（已执行，可复用）：
