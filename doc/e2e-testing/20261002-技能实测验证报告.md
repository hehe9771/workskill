## 实测踩中的 6 个坑（已回填 `~/.claude/skills/web-e2e/SKILL.md`）

1. **seed 跑完进程退出**：按官方文档写空 seed，`--debug=cli` 会话随测试结束销毁，"resume 后探索"不成立。修复：seed 末尾 `page.pause()` + `E2E_EXPLORE=1` 条件 skip。
2. **attach 后命令必须带 `-s=<会话名>`**：文档只示范 attach 本身，裸命令报 "browser not open"。
3. **探索/运行默认无窗口**：Playwright Test 默认 headless，`--debug=cli` 沿用 config——不显式 `use.headless: false` 用户全程看不到浏览器（用户实测投诉点）。
4. **共享后端必须 `workers: 1`**：并行 worker 与 fixture 清空竞态，产生 6/10 假失败（同页两条同名待办、计数错乱）。这是"假绿"的反面"假红"，同样返工。
5. **重渲染后 ref 失效**：DOM 更新后旧 ref 全废（"Ref e17 not found"），须重新 snapshot 或用语义 locator（实测语义 locator 跨重渲染稳定）。
6. **monocart 覆盖率三连坑**：`coverage: true` 无效（要对象形式）；数据须 fixture 内 `page.coverage.startJSCoverage` 手动收集；Chromium 判断禁用 project name 正则（`/chromium/i.test('mobile-chrome')`=false → 静默跳过、全绿假象），须用 `defaultBrowserType`；数值需 `reports: ['json-summary']`。
