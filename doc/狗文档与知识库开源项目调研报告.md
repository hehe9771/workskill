# 狗文档与知识库开源项目调研报告

> 调研日期：2026-07-06 ｜ 方法：Dynamic Workflow 多 agent 编排 + 对抗核验
> 调研目标：从 GitHub 检索"狗文档/狗知识库"类开源项目，覆盖品种数据库、护理指南、训练知识、健康知识、行为研究等维度，不少于 5 个，输出情况与对比

## 一、任务与方法

### 1.1 执行约束

- 本机无 `gh` CLI、无 `GITHUB_TOKEN`（未认证 GitHub REST API 限速 60 req/h/IP）
- 采用 **GitHub Search REST API（主线程控速）+ WebFetch 抓 github.com 网页与 raw.githubusercontent.com（不耗 API 配额，可并行）+ DuckDuckGo/Bing HTML 补充** 的三段式调研模式
- **防伪装执行**：所有 agent 的结构化输出强制带 `sources_fetched` 字段（每条 URL + fetch_status: success/failed + snippet），可一眼识别是否真抓取、有无编造；多处采用 API + 网页 + raw README 三源交叉验证

### 1.2 Workflow 编排

**单轮 `wf_dog-doc-kb-research`**：5 路并行检索 → 去重 → 逐项目对抗核验 → 综合

- Agent 1-3：GitHub Search API（英文 dog breed database / dog care guide / dog knowledge base + 中文"狗知识/犬种数据库"）
- Agent 4：WebFetch 抓 GitHub topic 页（dog / dog-breeds / veterinary / animal-care）+ 顺藤摸瓜抓组织仓库列表（如 onradar-dogs 12 个品种指南系列）
- Agent 5：WebFetch 打 DuckDuckGo/Bing HTML 补充 + 抓活站（dog.ceo、dogapi.dog、canmydogeat.netlify.app、bestdogbox.com、jthorvaldur.github.io/bulldogs、canineglioma.verhaaklab.com 等）
- 结果：45 候选 → 去重 → 深度调研 45 → **确认 37 个**，驳回 8 个

### 1.3 对抗核验机制

每个候选项目都经独立 agent 四角度尝试推翻：
1. **URL 是否 404/不存在**——API 返回状态、网页可达性、raw 文件可读性
2. **是否其实不是文档/知识库**——是否为 app/游戏/商店/纯工具/纯 ML 代码而非知识载体
3. **是否与狗无关**——猫/其他动物/无关项目误命中
4. **是否只是无关项目误命中关键词**——主题擦边 vs 实质相关

默认怀疑，证据不足即判 uncertain/refuted。**37 个最终确认项目均通过对抗核验（verdict=confirmed）**，8 个被驳回（角度②或③成功推翻）。

## 五、结论与选型建议

### 5.1 关键发现

1. **品种数据库（dog-breed-db）是 GitHub 上最丰富的狗知识库品类**——37 个确认项目中 21 个（57%）为品种数据库，数据格式涵盖 JSON/CSV/SQL/SQLite/API/图像，且 AKC/FCI 权威来源项目占主导
2. **高 star 项目多为 API 服务而非静态文档**——dog-ceo-api(712)、dog-api-images(419)、dogapi.dog(176) 均为 API/图像后端，纯文档知识库 star 极低（多为 0）
3. **狗健康/营养/行为知识库严重稀缺**——健康类仅 3 个（含 1 个学术论文站、1 个皮肤专科、1 个多物种诊断规则）、营养类仅 1 个（can-my-dog-eat）、行为类仅 3 个（含 2 个学术论文制品库）
4. **数据质量管控意识正在兴起**——gsusI/dog-breeds-database 的 reviewed/needs-review/seeded 三态审核 + source_registry 溯源字段、bestdogbox 的 "verify all changes against AKC and breed club sources"、awesome-animal-care 的 Not By AI 90% Rule 均体现了对 AI 生成内容的抵制与权威来源核验
5. **AI 辅助生成与循证核验并存**——jthorvaldur/bulldogs 的 topics 含 claude-api 但同时含 18 篇同行评议文献与 4 级证据核查方法论；210romero210-a11y 含 CLAUDE.md/AGENTS.md
6. **与"宠物行为知识库"调研重叠的 3 个项目**（sstroell 系列 + dog-curriculum）仍属该领域最活跃的文档型贡献者，但 sstroell 方法论偏概念化、缺科学文献支撑

### 5.3 局限性

- **API 限速影响**：GitHub REST API 未认证 60 req/h 在 37 个项目的核验过程中多次耗尽（IP 47.237.28.48），多处改用 WebFetch 抓 github.com 网页与 raw.githubusercontent.com 完成验证；部分项目（Dog-Facts-API-v2、NachoHotz/Dogspedia、stellageorgiou/DogBreedDatabase 等）的精确 pushed_at 未能结构化获取
- **未覆盖 HuggingFace Datasets、Zenodo、Kaggle 等数据集平台**（仅限 GitHub）；Zenodo 上的犬类行为研究数据集（如 ccbs-study-3/pdbs-study-3 的 Zenodo DOI）未纳入
- **中文狗知识库在 GitHub 上覆盖稀疏**（"狗知识/犬种数据库"中文关键词未单独命中高质量中文仓库）；若需中文来源，建议补搜知乎/CSDN/哔哩哔哩及 HuggingFace Datasets
- **0 star 项目的知识可信度未经第三方验证**，使用前应交叉核对来源（尤其是 sstroell 系列的自创术语方法论、lurnake 的 Gemini-2.0-Pro 评分数据）
- **3 个重叠项目**（sstroell 系列 + dog-curriculum）的详细评估已在"宠物行为知识库 GitHub 调研报告"中完成，本报告仅作交叉引用标注，不重复展开
