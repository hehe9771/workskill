# 猫狗语音开源模型检索与对比

> 检索日期：2026-07-06
> 方法：Dynamic Workflow（多模态并行搜索 → 对抗核验 → 综合对比）
> 规模：46 agents / 271 万 token / 420 工具调用 / 24 分钟
> 数据源：HuggingFace、GitHub、PapersWithCode、ModelScope（魔搭）、Kaggle、DuckDuckGo 全网

---

## 一、概述与方法论

### 1.1 任务解读

"猫狗语音开源模型" = 能识别/处理猫、狗声音的开源模型，本次检索覆盖五个子任务：

1. **猫叫声识别**（cat meow/sound recognition）
2. **狗叫声识别**（dog bark/sound recognition）
3. **猫狗声音二分类**（cat vs dog audio classification）
4. **宠物声音/语音翻译**（pet voice translation / animal-human communication）
5. **通用动物声音识别中含猫狗类别**（animal sound classification covering cat/dog，如基于 AudioSet/ESC-50 的 AST/YAMNet/PANNs 等）

### 1.2 Workflow 结构

| 阶段 | 内容 | agent 数 |
|------|------|---------|
| Phase 1 多模态搜索 | 6 路并行 finder 真实 WebFetch：HuggingFace / GitHub / PapersWithCode+学术 / 魔搭中文社区 / Kaggle / DuckDuckGo 全网 | 6 |
| Phase 2 对抗核验 | 跨 finder 去重后，每个候选独立重抓，核验存在性/开源/猫狗任务匹配 | 39 |
| Phase 3 综合对比 | 分类 + 对比表 + 场景推荐 + 检索缺口 | 1+ |

### 1.3 防伪装执行设计（用户硬性要求）

- 每个 finder **必须真实调用 WebFetch** 抓取指定 URL，禁止凭训练记忆编造
- 每条候选 `evidence` 字段粘贴从网页真实抓取的原文片段（含关键词）
- `sources_fetched` 如实记录每个 URL 的 `success`/`failed` 状态，403/超时不得编造内容
- 核验阶段默认怀疑态度，**独立重抓**尝试推翻上一步声称
- 结构化 schema 强制约束输出，无法编造字段

## 三、整体现状总结

1. **通用动物声音分类模型丰富且成熟**：基于 AudioSet（527 类含 Cat/Dog/Meow/Bark 等）和 ESC-50（50 类含 Dog/Cat）的 AST、PANNs、YAMNet、HuBERT 等基础模型多、质量高、license 明确。代表性模型 MIT/ast-finetuned-audioset（HF 月下载 53.5 万、bsd-3-clause）、YuanGongND/ast（GitHub 1.5k stars）、earthspecies/aves（"动物界 BERT"、MIT、142 stars）覆盖猫狗作为子类别，可微调到猫狗任务。

2. **专门做猫狗声音二分类的高质量预训练模型稀缺**：仅 `dima806/cat_dog_sounds_classification` 一个（HF+ModelScope 双平台、apache-2.0、wav2vec2），但月下载仅 3-56 次、模型卡极简、知名度低。其余猫狗二分类多为 GitHub 个人练手项目（无 license、0 stars、无权重）或 Kaggle notebook。

3. **猫叫识别方向有若干开源项目但多为小项目**：Skyler-Luo/CatMeows-Recogintion（MIT、MFCC+SVM）、IsolaHGVIS/Cat-Meow-Classification（MIT、CNN+权重可下载）较可用；universalml/catsound、Jacobtent/right-meow 因无 license 或模型卡空白判 uncertain。

4. **狗叫识别方向资源相对较好**：lincolnhard/dog-bark-detector（Darknet CNN+预训练权重）、Woof-AI/WOOF_recognition（VGGish+AST）、jatacid/dogbarkingdetector（YAMNet+TF.js 浏览器端）、SolomonGithu/tinyml（ESP32 端侧）覆盖不同部署场景。

5. **宠物翻译方向基本空白**：无任何经验证的开源宠物声音翻译模型。Hakeem750/pet-sound-to-texts 为 Whisper 空模板（uncertain）；FrogBoss74/RealCatTranslator 仅规划阶段无 ML 代码；skanak9/Animal-translator 被证伪。商业产品（MeowTalk、BowLingual）未开源。

6. **数据集资源较丰富**：Kaggle audio-cats-and-dogs（CC BY-SA 3.0、1.9 万下载）、Cats vs Dogs: Audio Classification（CC BY 4.0）、CatMeows（Zenodo、440 段 21 只猫 3 情境）、ESC-50（CC BY-NC、含 Dog/Cat）、Dog voice emotion dataset（Apache 2.0）等可直接用于训练。

7. **license 缺失是普遍问题**：多个 GitHub 个人项目（1fmusic、lincolnhard、Ujjwal9302、Jacobtent、fadymaher24）无 LICENSE 文件，按 GitHub 默认 all rights reserved，法律上不可直接商用。

## 六、按子任务分类详述

### 一、猫叫识别（6 个，含 2 个 uncertain）

**开源可用模型/代码：**
- **Skyler-Luo/CatMeows-Recogintion**（GitHub, MIT, confirmed）：MFCC 特征(240维) + SVM(RBF核) 分类器，区分 Brushing/UnfamiliarSurroundings/WaitForFood 三种猫行为状态，10 折交叉验证，2 stars，轻量易复现
- **IsolaHGVIS/Cat-Meow-Classification**（HF, MIT, confirmed）：CNN+BatchNormalization，输入 Mel 频谱图(128x174x1)，权重 best_model_fold_2.h5 可下载（gated=auto 自动审批），三类情境，基于 Kaggle andrewmvd/cat-meow-classification 训练
- **Cat Meow Classification**（Kaggle notebook, confirmed）：基于 CatMeows 数据集（440 段、21 只猫、3 情境）的猫叫分类 notebook，代码可 fork
- **Cat Sound Classification**（Kaggle notebook, confirmed）：使用 Cat Meow Classification 数据集的猫叫声分类 notebook

**存疑候选：**
- **universalml/catsound**（HF, uncertain）：wav2vec2 从零训练，但 config.json 的 id2label={0:angry,1:happy,2:noise} 实为情绪三分类非猫狗区分，模型卡完全空白，无 license，月下载仅 1
- **Jacobtent/right-meow**（GitHub, uncertain）：CNN/CNN-LSTM 两变体 + MFCC，440 条猫叫 3 类意图，权重 best_cat_meow_model.keras 可下载，但无 license，0 stars

**关联数据集：** CatMeows（Zenodo 4008297，440 段猫叫录音，21 只猫 2 品种 Maine Coon/European Shorthair，3 种情境 brushing/isolation/waiting for food）

### 二、狗叫识别（5 个 confirmed + 1 个数据集）

**开源可用模型/代码：**
- **lincolnhard/dog-bark-detector**（GitHub, confirmed, 无 license）：Darknet CNN 做频谱图分类，**含预训练权重** weights/dogbark_32.weights，支持文件与麦克风实时检测（PortAudio），UrbanSound top-1 约 95%、ESC-50 约 80%，32 stars，2018 年后未更新
- **SolomonGithu/tinyml_dog_bark_and_howl_classification**（GitHub, MIT, confirmed）：Edge Impulse + Keras，MFCC+神经网络，TFLite Micro int8 部署于 XIAO ESP32S3，狗叫+狗嚎+噪声三分类，验证 97.6%/测试 99.0%，数据由 ElevenLabs 合成，4 stars
- **Woof-AI/WOOF_recognition**（HF, MIT, confirmed）：VGGish+STFT 特征提取 + AST 自注意力分类，barking/non-barking 二分类，ast_model.pth(349MB) 权重可下载，噪声环境鲁棒
- **jatacid/dogbarkingdetector**（GitHub, MIT, confirmed）：YAMNet 转 TensorFlow.js，521 类中聚焦 Dog/Bark/Yip 等(classes 70-75)，浏览器端离线实时麦克风检测，16kHz 客户端推理，10 stars

**关联数据集：** Dog voice emotion dataset (Demo-Lite)（Kaggle, Apache 2.0, 163 条狗声音录音, 4 种类型, 694 downloads）

### 三、猫狗声音二分类（8 个 confirmed + 1 个 uncertain + 2 个数据集）

**预训练模型（可直接用）：**
- **dima806/cat_dog_sounds_classification**（HF + ModelScope 双平台, apache-2.0, confirmed）：wav2vec2 (Wav2Vec2ForSequenceClassification) 微调自 facebook/wav2vec2-base-960h，94.6M params，config.json 的 id2label={0:cat,1:dog} 直接证明猫狗二分类，**唯一专门做猫狗二分类的预训练模型**，但月下载仅 3-56 次、模型卡极简

## 八、检索缺口

### 1. 宠物翻译方向基本空白（最大缺口）
- 无任何经验证的开源宠物声音翻译模型。Hakeem750/pet-sound-to-texts 为 Whisper 空模板（无训练数据/无评估/无 license，不可验证）；FrogBoss74/RealCatTranslator 仅规划阶段无 ML 代码；skanak9/Animal-translator 被证伪（实为 Animalese 语音合成）。
- 商业产品（MeowTalk、Petpuls、BowLingual）均为闭源。
- **缺失：宠物声音到人类语义的端到端翻译开源模型；猫狗情绪/意图到文本的映射模型。**

### 2. 专门做猫狗声音二分类的高质量预训练模型稀缺
- 仅 dima806/cat_dog_sounds_classification 一个（月下载 3-56，模型卡极简，训练数据未命名，知名度极低）。
- 其余猫狗二分类多为 GitHub 个人练手项目（无 license、0 stars、无权重）或 Kaggle notebook（无显式 license）。
- **缺失：大规模猫狗声音数据集训练、有完整模型卡和评估指标、license 明确的高质量二分类模型。**

### 3. 猫叫声识别多为个人小项目，成熟度不足
- 多数 0-2 stars，影响力有限。universalml/catsound 模型卡空白 + 无 license + 实为情绪三分类；Jacobtent/right-meow 无 license；Cat Meow/Sound Classification 两个 Kaggle notebook 因 JS 渲染/登录墙无法核验架构。
- **缺失：有完整文档、license 明确、大规模数据训练、有标准评估的猫叫声识别模型。**

### 4. 狗叫识别的现代化预训练权重模型较少
- 多数依赖 YAMNet 迁移学习或传统 ML。lincolnhard/dog-bark-detector 无 license 且 2018 年后未更新；Woof-AI/WOOF_recognition 模型卡未注明训练数据集。
- **缺失：现代化架构、license 明确、有完整训练数据说明的狗叫专用大模型。**

### 5. 品种维度缺失
- 猫狗声音本身不分语种，但品种维度缺失（不同品种猫狗叫声差异大）。CatMeows 仅 21 只猫 2 品种（Maine Coon/European Shorthair），品种覆盖窄；Dog voice emotion dataset 仅 163 条 4 类无品种标注。
- **缺失：多品种猫狗声音数据集及品种感知模型。**

### 6. 中文语境下的猫狗声音研究缺失
- 检索到的开源模型/数据集均为英文/国际来源（HF/ModelScope/GitHub/Kaggle/Zenodo），无中文标注的猫狗声音数据集或模型。
- ModelScope 上虽有镜像（dima806、Xenova、speechbrain、pengzhendong 等），但均为国际模型的中文平台镜像，非中文原生研究。
- **缺失：中文标注的猫狗声音数据集、中文社区的猫狗声音识别模型。**

### 7. 端到端可用的宠物声音理解系统缺失
- 现有资源要么是基础模型（AST/AVES/YAMNet，需微调）要么是数据集（需训练）要么是零散代码（无权重）。
- **缺失：开箱即用、覆盖猫狗多情绪/多意图/多场景的成品开源系统（如猫狗声音识别 + 情绪分析 + 含义翻译的一体化 pipeline）。**

### 8. 评估基准和标准缺失
- 多数模型无统一评估，准确率数字不可比（数据集不同、划分不同、指标不同）。dima806 无评估指标；AST 用 AudioSet mAP；speechbrain 系列用 ESC-50 accuracy；lincolnhard 用 UrbanSound/ESC-50 top-1。
- **缺失：猫狗声音识别的标准评测基准、公开排行榜、统一测试集。**

### 9. 野外/真实环境数据缺失
- 现有数据集多为干净录音（CatMeows 实验室录制、Audio Cats and Dogs 单一来源）。SolomonGithu/tinyml 用 ElevenLabs 合成语音而非真实狗叫。
- **缺失：真实家庭环境、多背景噪声、多距离、多设备的猫狗声音野外数据集。**

### 10. 猫狗声音生成/合成方向缺失
- 检索未发现任何开源的猫狗声音生成模型（如基于 Diffusion/GAN 的猫叫/狗叫合成）。
- **缺失：猫狗声音生成模型（可用于数据增强、虚拟宠物、游戏等场景）。**
