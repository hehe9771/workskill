# 审计 Workspace 原型

> 基于 AI Native 金融机构框架的碳硅协同审计系统概念验证

## 架构设计

```
┌─────────────────────────────────────────────────────────────┐
│                    审计 Workspace                             │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  人类角色                                                    │
│  ┌─────────────┐                                           │
│  │ 审计经理    │ ← 审核、决策、最终签字                       │
│  └──────┬──────┘                                           │
│         │ 审核点 1                 审核点 2                  │
│         ▼                          ▼                       │
│  ┌─────────────────────────────────────────────────────┐   │
│  │              Agent 团队（硅基员工）                    │   │
│  │  ┌─────────┐  ┌─────────┐  ┌─────────┐  ┌─────────┐ │   │
│  │  │数据收集 │→│财务分析 │→│合规检查 │→│报告生成 │ │   │
│  │  │专员     │  │师       │  │员       │  │员       │ │   │
│  │  └─────────┘  └─────────┘  └─────────┘  └─────────┘ │   │
│  └─────────────────────────────────────────────────────┘   │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

## Agent 角色定义

| Agent | 职责 | 输入 | 输出 |
|-------|------|------|------|
| **数据小助手** | 收集被审计单位财务数据、行业基准 | 公司名称 | 财务数据 + 行业对标 |
| **财析君** | 分析财报、计算财务比率、识别异常 | 财务数据 + 基准 | 异常指标 + 审计发现 |
| **合规卫士** | 核对会计准则、监管要求 | 公司信息 | 合规检查项 + 发现 |
| **报告能手** | 汇总发现、生成审计报告 | 所有发现 | 结构化审计报告 |
| **张经理（人类）** | 审核 Agent 输出、最终决策 | 审计发现 + 报告 | 审批/驳回 + 下一步 |

## 工作流程

```
1. 人类下达审计目标
   ↓
2. 数据小助手 → 收集财务数据、行业基准
   ↓
3. 财析君 → 分析财务指标，识别异常（偏离行业 >20%）
   ↓
4. 合规卫士 → 核对会计准则、监管要求
   ↓
5. 【人类审核点 1】审计经理审核审计发现
   ↓
6. 报告能手 → 生成审计报告
   ↓
7. 【人类审核点 2】审计经理最终审核
   ↓
8. 输出最终结果（同意出具报告 / 需进一步调查）
```

## 运行方式

```bash
python audit_workspace.py
```

输出保存到 `output.txt`。

## 核心代码结构

```
audit_workspace.py
├── 基础数据结构
│   ├── RiskLevel（风险等级枚举）
│   ├── AuditFinding（审计发现）
│   └── FinancialMetric（财务指标）
├── Agent 基类
│   └── BaseAgent
├── 四个专业 Agent
│   ├── DataCollectorAgent
│   ├── FinancialAnalystAgent
│   ├── ComplianceCheckerAgent
│   └── ReportGeneratorAgent
├── 人类角色
│   └── AuditManager
└── Workspace 编排器
    └── AuditWorkspace
```

## 与理论框架的对应

| 理论概念 | 本原型实现 |
|---------|-----------|
| **AI Factory** | Agent 角色定义（能力圈） |
| **AI Workspace** | 多 Agent 协作 + 人类审核点 |
| **碳硅协同** | 4 个 Agent（硅基）+ 1 个经理（碳基） |
| **Hooks 机制** | 人类审核点（关键节点复核） |
